# 🧭 MindMap.AI — Turn Chaos Into Clarity  

> _An AI-powered mind-mapping tool that transforms unorganized thoughts into structured visual hierarchies, insights, and diagrams._  

---

## 🚀 Overview
**MindMap.AI** helps users instantly convert messy text or brainstorming notes into **organized mind maps** — complete with hierarchy, flow, and actionable insights.  
Built entirely by **prompting**, it demonstrates how AI can act as a structured-thinking assistant instead of just a content generator.  

---

## ✨ Features
- 🧠 **AI Hierarchy Extraction** – Understands context and organizes ideas logically.  
- 🌐 **Interactive MindMap Visualization** – Auto-generates diagrams using Mermaid.js.  
- 💡 **Insight Summarization** – Extracts key takeaways and focus areas.  
- 🎨 **Futuristic UI** – Clean glassmorphism theme with gradient background.  
- ⚙️ **Prompt-Built Intelligence** – Powered by Google AI Studio (Gemini 1.5 Pro) + Firebender SDK.  

---

## 🧩 How It Works
1. Paste your unorganized ideas or notes.  
2. AI analyzes and builds a structured hierarchy.  
3. Mermaid.js renders a visual mind map.  
4. AI summarizes key insights for clarity.  

Built entirely through **Google AI Studio** for rapid deployment and **Firebender SDK** for on-device AI logic.

---

## 🛠️ Tech Stack
- **AI Core:** Gemini 1.5 Pro (Google AI Studio)  
- **Visualization:** Mermaid.js  
- **Interface:** HTML + CSS + JavaScript (Glassmorphism design)  
- **Optional:** Firebender SDK for local AI execution  

---

## 💡 Example Use Case
Input:
> “AI project to monitor campus food waste, connect NGOs, and reward students for sustainability.”

Output:
- AI generates a hierarchy of ideas.  
- Creates a live mind map diagram.  
- Provides 3-5 key insights for improvement.
